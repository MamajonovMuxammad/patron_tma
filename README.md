# Barbershop «PATRON» (@patron_99_uz) • Tashkent
## Telegram Mini App (TMA) + Spring Boot 3 Backend + Telegram Bot

Полноценная система онлайн-записи и управления записями для сети барбершопов **«PATRON»** (г. Ташкент).

> **Главное бизнес-преимущество:** Бюджет на платные сторонние API = **$0**. Вся авторизация, Anti-No-Show подтверждения визитов, авто-напоминания и уведомления мастеров работают на 100% бесплатно через официальный Telegram Bot API и Telegram WebApp SDK без платных SMS-шлюзов.

## 🎯 Реализованный функционал

### 1. Реальные данные сети «PATRON» (Ташкент)
- **3 филиала (09:00 – 21:00 без выходных):**
  1. *Максим Горький (Буюк Ипак Йули)* — ул. Мирзо Улугбека, 49/3 (+998 95 023 20 00)
  2. *Карасув* — массив Карасув-1 (напротив Korzinka) (+998 99 595 40 00)
  3. *Салом Чайхана* — ул. Шуъала (ор-р Салом чайхана) (+998 70 037 60 00)
- **9 мастеров** (по 3 на каждый филиал: Шохазиз Top Barber 5.0, Сайфулла Senior 4.95, Сардор 4.9 и др.)
- **5 реальных услуг** с автоматическим суммированием длительности и стоимости в сумах (UZS):
  - Мужская стрижка (45 мин — 100 000 сум)
  - Стрижка + Борода Комплекс (60 мин — 140 000 сум)
  - Моделирование бороды (30 мин — 60 000 сум)
  - Детская стрижка до 10 лет (30 мин — 70 000 сум)
  - Чистка лица Black Mask + Воск (30 мин — 60 000 сум)

### 2. Клиентский интерфейс Telegram Mini App
- **Премиальный темный дизайн:** глубокий угольно-черный фон `#09090B`, матовые карточки `#141418` с фиолетовой неоновой обводкой `rgba(139, 92, 246, 0.22)` и акцентом `#7C3AED`.
- **Фича «Кто свободен прямо сейчас?»** с пульсирующим зеленым индикатором и быстрой записью в 1 клик.
- **Двуязычный интерфейс (RU / UZ):** мгновенное переключение языка в 1 тап.
- **Опция «Любой свободный мастер»:** для тех клиентов, кто хочет записаться на ближайшее доступное время.
- **Расчет свободных слотов с защитой от пересечений:** 09:00 – 21:00 с шагом 30 минут.
- **Удобная маска телефона Узбекистана:** `+998 (__) ___-__-__`.
- **Раздел «Мои записи»:** просмотр активной брони, переход к маршруту в 2ГИС/Яндекс.Картах и отмена в 1 тап.
- **Нативная интеграция Telegram SDK:** `WebApp.expand()`, `HapticFeedback.impactOccurred()`, чтение профиля пользователя.

### 3. Anti No-Show Engine (Борьба с неявками через Telegram-бота)
- При создании записи: мгновенный пуш клиенту с деталями и инлайн-кнопкой `❌ Отменить запись`, а также уведомление барберу/админу в Telegram.
- **Авто-напоминание за 2 часа:** задача по расписанию (`@Scheduled` каждые 5 минут в Spring Boot) находит записи со статусом `PENDING_CONFIRMATION` за <= 120 минут до визита и отправляет клиенту интерактивные кнопки:
  - `✅ Точно приду! (Tasdiqlash)` -> переводит в статус `CONFIRMED`.
  - `❌ Не смогу прийти (Bekor qilish)` -> освобождает слот и уведомляет салон.

### 4. Панель Барбера и Администратора
- Переключатель «Клиент | Админ» прямо в шапке для наглядной демонстрации владельцу.
- Статистика за сегодня: количество записей, ожидаемая выручка в сумах, свободные окна, неявки.
- Расписание на сегодня с цветовой индикацией (Желтый: ожидает, Зеленый: подтвержден, Фиолетовый: выполнен, Красный: неявка, Оранжевый: живая очередь).
- **Кнопка «⚡ Быстрый блок слота (Клиент с улицы)»:** мгновенное закрытие любого окна в расписании для гостей по живой очереди.
- Кнопки управления: «Пришел / Завершить», «Не явился (No-Show)», «Позвонить клиенту».

## 🚀 Быстрый запуск проекта

### 1. Запуск Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на: `http://localhost:5173/`

### 2. Запуск Backend (Java 21 + Spring Boot 3)
```bash
cd backend
# На Windows:
.\mvnw.cmd spring-boot:run

# На macOS / Linux:
./mvnw spring-boot:run
```
Бэкенд запустится на: `http://localhost:8080/`
H2 Консоль базы данных: `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:file:./data/patrondb`)

## 🤖 Пошаговая настройка Telegram-бота в BotFather за 5 минут

1. Откройте Telegram и перейдите к [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и задайте имя:
   - Имя: `Barbershop PATRON Tashkent`
   - Юзернейм: например `patron_99_bot` (или любой свободный).
3. Скопируйте полученный **HTTP API Token**.
4. Создайте Mini App команду:
   - Отправьте `/newapp` в BotFather.
   - Выберите вашего бота.
   - Укажите название: `PATRON Online`
   - Загрузите иконку (640x360 px) или пропустите.
   - Введите WebApp URL (например, ваш ngrok URL или URL хостинга: `https://your-domain.com` или локальный через туннель `https://xxxx.ngrok-free.app`).
5. Настройте кнопку меню в боте:
   - Отправьте `/setmenubutton`.
   - Выберите бота, введите текст кнопки: `💈 Записаться в PATRON` и укажите URL вашего Mini App.
6. Вставьте ваш токен в `backend/src/main/resources/application.yml` или передайте переменную окружения:
   ```bash
   $env:TELEGRAM_BOT_TOKEN="ваш_токен_из_botfather"
   $env:TELEGRAM_ADMIN_CHAT_ID="ваш_telegram_id"
   ```
